# Contributing to PxC

Thank you for helping! PxC is developed by one person, so the way to contribute is through **issues**:

- **Bug reports, feature requests and questions are welcome.** Open an issue and pick the matching template.
- **Pull requests are not accepted.** Please describe the change in an issue instead; good ideas go into the next
  versions.

## A good bug report

- Say what you did, what you expected and what happened instead.
- Paste the **PxC report**: gear window ▸ **Other settings** ▸ **Copy report**. It lists the PxC, Python, PhotoCraft
  and ComfyUI versions and your settings; it contains no prompts and no access tokens.
- Name the model and the function, your operating system and your graphics card with its VRAM.
- A screenshot of the window often says more than a description.

## Response time

Every issue is read, but there is no promised response time.

## Security

Please do not report security problems as public issues; see [SECURITY.md](SECURITY.md).
